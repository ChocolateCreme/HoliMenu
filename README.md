In this project, I'm rebuilding the in-store menu for Holi Restaurant in Bedford, Massachusetts. The link to the original site is https://www.holibedford.com/instore-menu/. I used npm run dev to run my project locally.
I implemented a feature where users can search up a category that they may not know the meaning of. I added this interaction because I felt like it would be helpful for people who may not be too familiar with Indian food or Holi Restaurant in general. Next, I am planning to add a navigation bar at the bottom of the page to help users with dietary restrictions learn what meals would be the best for them. I put the navbar in but didn't get a chance to work on it yet.
My original wesbite is the Holi Indian Restaurant Menu (in Bedford, Massachusetts). The link is https://www.holibedford.com/instore-menu/. I chose to recreate the menu because in the original website, it looked disorganized. I also added a feature to help users understand what each food category features. As for the design, I added beautiful Holi (the holiday in which people through colored powders at each other in India and what the restaurant is named after) colors in the background. I also changed the Header to have India's offical colors (red and gold) and changed the background colors of some components to look like India's flag. Some future improvements would include adding a filter to the food cards to help users find them easier and help improve user experience. Another improvement would be to add something to help users with specific food restrictions (gluten free, nut allergy, vegan) to find foods that meet their needs. I actually tried adding a navbar to make pages for that but it didn't end up working out at the end. Finally the last improvement would be to change the search category feature to search categories based on the first letter of the name and not just any letter in the string itself. Other than that, I am proud of how the final result ended up looking like and I know I learned a lot of new things in the process.
